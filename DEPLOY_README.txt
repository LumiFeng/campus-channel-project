校园渠道项目网站｜受控静态托管包

部署方式：直接上传本 ZIP，index.html 位于压缩包根目录。

运行说明：
1. 网站为纯静态单页应用，不需要 Python、Node 或数据库服务。
2. CSS 与 JavaScript 已内联在 index.html 中。
3. 图片、活动报告和网页幻灯片均在包内，并使用相对路径引用。
4. 网站不访问外部 CDN、远程图片、公司后端或管理 API，也不包含服务端密钥。
5. 当前版本为只读内容站点，不使用 window.HRAI_STORAGE；后续如需增加收藏、备注等 JSON 数据，可在内网 SSO 环境下接入。
6. 上传新 ZIP 可整体替换网站文件；请保留现有站点的访问名单与数据空间配置。
7. 三份原 PPT 已转换为 43 页 JPG 图片和本地 HTML 查看器，浏览器可直接翻页和全屏查看。
8. 三份演示文稿同时提供 PDF 下载；数据分析报告支持网页预览与 HTML 文件下载。
9. 为兼容受控托管平台，创意素材使用 PNG/JPG，网站不再依赖 WebP 格式，也不额外声明页面 CSP。
